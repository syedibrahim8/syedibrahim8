## About

I'm a full stack developer based in Riyadh, working mostly with TypeScript, React, Next.js, Node.js and MongoDB. I graduated in Computer Science and Engineering from JNTU Hyderabad in 2026, after a 16-week Full Stack + AI bootcamp at Code for India Foundation where I built production-style apps in a small Agile team.

The work I enjoy most sits where real problems meet careful engineering: role-based access, payments, background jobs, and interfaces simple enough for anyone to use. I'm now extending that into AI — LLM integration, tool calling and agents.
